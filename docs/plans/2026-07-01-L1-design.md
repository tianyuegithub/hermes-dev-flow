# L1 设计 · 容器化 Worker + K3s Pod 热池 + Redis Spec 传递
# 2026-07-01 v2 · 评审后修订

> 目标：把 worker 从"本地子进程"搬到"K3s pod 热池"。
> spec 存 Redis，节点间只传 task_id。
> Pod 跑完 reset，供下个任务复用（设计文档 §5）。
> L0 本地模式保留，intake 选 mode: local|pod。

---

## 架构

```
Hermes (Mac)
  ├── intake.py        写 spec 到 Redis
  ├── kubectl          调度任务到热池中的 pod
  ├── Redis 轮询       读 output + 心跳
  └── gitea_pr.sh      不变

K3s Pod 热池 (dev-flow namespace)
  ├── Pod-1 (deer-flow)  ← 常驻，串行接任务，跑完 reset
  ├── Pod-2 (deer-flow)  ← 并发时扩容
  └── ...

Redis (infra namespace, 已有)
  └── spec:<id> / output:<id> / heartbeat:<id> / status:<id>
```

## 1. Pod 热池 + Reset 契约

### 热池设计（设计文档 §5）

```
项目 : Pod = 1 : 多。并发来自起更多 Pod。
Pod : 任务 = 同一时刻 1:1（串行）。跑完 reset，复用。
隔离 = 每 pod 一份私有 clone + 独立分支。
```

### Reset 契约（每次任务完成后强制执行）

Pod 完成一个任务后，必须 reset 到干净状态才能接下一个：

```bash
# reset.sh — 在 Pod 内执行
cd /workspace/repo
git fetch origin
git checkout main              # 回到基线分支
git branch -D dev-flow/* 2>/dev/null || true  # 删所有工作分支
git clean -fdx                 # 清理未追踪文件 + 构建产物
git reset --hard origin/main   # 硬重置
# 验证
test -z "$(git status --porcelain)" && echo "RESET OK" || echo "RESET DIRTY"
```

### Pod 状态机

```
IDLE        ← 等任务，热池待命
BUSY        ← 正在执行任务（status:<id>=running）
RESETTING   ← 任务完成，执行 reset 契约
IDLE        ← reset 完成，回到待命
```

Pod 状态存在 Redis：`pod:<pod-name>:state` = `idle|busy|resetting`

### Pod 接任务的流程

```bash
# worker-entrypoint.sh 的主循环（常驻）
while true; do
  # 1. 等待 Hermes 派任务
  TASK_ID=$(redis-cli BLPOP pod:$POD_NAME:queue 0)  # 阻塞等待

  # 2. 标记 BUSY
  redis-cli SET pod:$POD_NAME:state busy
  redis-cli SET status:$TASK_ID running

  # 3. Fetch spec
  dev-flow-spec fetch "$TASK_ID" > /tmp/input.json

  # 4. 心跳
  while true; do
    STATUS=$(redis-cli GET status:$TASK_ID)
    [ "$STATUS" != "running" ] && break  # 完成或升级后停心跳
    dev-flow-spec heartbeat "$TASK_ID"
    sleep 30
  done &

  # 5. Git prepare
  git fetch origin
  git checkout -B "dev-flow/$TASK_ID" origin/main
  git clean -fdx

  # 6. Build prompt + Run Claude Code
  # ... (同 L0)

  # 7. Submit output
  dev-flow-spec submit "$TASK_ID" /tmp/output.json

  # 8. Push branch
  git push origin "dev-flow/$TASK_ID"

  # 9. Reset（复用纪律）
  redis-cli SET pod:$POD_NAME:state resetting
  bash /usr/local/bin/reset.sh
  redis-cli SET pod:$POD_NAME:state idle
done
```

## 2. Spec 传递（Redis 引用传递）

### Redis Key 设计

```
spec:<task_id>              ← 输入契约（Hermes 写，Pod 读）
spec:<task_id>:v<N>         ← 版本化（打回 = v2，v1 留痕）
output:<task_id>            ← 输出契约（Pod 写，Hermes 读）
heartbeat:<task_id>         ← 心跳（Pod 每 30s 写，TTL 60s）
status:<task_id>            ← 任务运行状态（Pod 写：running/done/escalate）
escalate:<task_id>          ← 逃生舱（Pod 写）

pod:<pod_name>:state        ← Pod 状态（idle/busy/resetting）
pod:<pod_name>:queue        ← 任务队列（BLPOP 阻塞等待）
```

### Hermes 端派任务

```bash
# 写 spec 到 Redis
redis-cli -h 192.168.31.173 -p 32319 SET "spec:$TASK_ID" "$(cat input.json)"

# 找一个 IDLE pod
POD=$(redis-cli -h 192.168.31.173 -p 32319 GET pod:dev-flow-worker-1:state)
if [ "$POD" = "idle" ]; then
  # 派任务
  redis-cli -h 192.168.31.173 -p 32319 RPUSH "pod:dev-flow-worker-1:queue" "$TASK_ID"
else
  # 没有 idle pod → 起 Pod-2 或等待
  kubectl scale deploy dev-flow-worker --replicas=2 -n dev-flow
  # 等新 pod ready 后派任务
fi
```

### Hermes 端轮询结果

```bash
while true; do
  STATUS=$(redis-cli -h 192.168.31.173 -p 32319 GET "status:$TASK_ID")
  case "$STATUS" in
    done)     echo "✅ 完成"; break ;;
    escalate) echo "🚨 逃生舱"; break ;;
    blocked)  echo "❌ 失败"; break ;;
    running)
      # 检查心跳
      HB=$(redis-cli -h 192.168.31.173 -p 32319 GET "heartbeat:$TASK_ID")
      if [ -z "$HB" ]; then
        echo "⚠️ 心跳丢失 — 可能卡死"
      fi
      ;;
  esac
  sleep 10
done
```

### dev-flow-spec（修复缺陷 1：用 os.environ 不用 heredoc）

```bash
#!/bin/bash
# dev-flow-spec — Worker 端的 Redis spec 访问工具
REDIS_HOST="${REDIS_HOST:-redis.infra.svc.cluster.local}"
REDIS_PORT="${REDIS_PORT:-6379}"

case "$1" in
  fetch)
    redis-cli -h "$REDIS_HOST" -p "$REDIS_PORT" GET "spec:$2"
    ;;
  submit)
    redis-cli -h "$REDIS_HOST" -p "$REDIS_PORT" SET "output:$2" "$(cat "$3")"
    redis-cli -h "$REDIS_HOST" -p "$REDIS_PORT" SET "status:$2" "done"
    ;;
  heartbeat)
    # 修复缺陷 2：先检查是否已完成
    STATUS=$(redis-cli -h "$REDIS_HOST" -p "$REDIS_PORT" GET "status:$2")
    if [ "$STATUS" != "running" ]; then
      exit 0  # 任务已结束，停心跳
    fi
    redis-cli -h "$REDIS_HOST" -p "$REDIS_PORT" SET "heartbeat:$2" "$(date +%s)" EX 60
    ;;
  escalate)
    redis-cli -h "$REDIS_HOST" -p "$REDIS_PORT" SET "escalate:$2" "$(cat "$3")"
    redis-cli -h "$REDIS_HOST" -p "$REDIS_PORT" SET "status:$2" "escalate"
    ;;
  *)
    echo "用法: dev-flow-spec fetch|submit|heartbeat|escalate <task_id> [file]"
    exit 1
    ;;
esac
```

### worker-entrypoint.sh（主循环，修复缺陷 1 + 2 + 3）

```bash
#!/bin/bash
set -euo pipefail

export TASK_ID=""  # 从队列获取

REDIS_HOST="${REDIS_HOST:-redis.infra.svc.cluster.local}"
REDIS_PORT="${REDIS_PORT:-6379}"
POD_NAME="${POD_NAME:-dev-flow-worker-1}"
REPO_URL="${REPO_URL:?必须设置 REPO_URL}"

# 首次 clone（pod 启动时一次性）
echo "[worker] 首次 clone..."
git clone --depth 1 "$REPO_URL" /workspace/repo
cd /workspace/repo

# 标记 IDLE
redis-cli -h "$REDIS_HOST" -p "$REDIS_PORT" SET "pod:$POD_NAME:state" "idle"

# 主循环 — 常驻接任务
while true; do
  echo "[worker] 等待任务..."

  # 阻塞等待任务
  TASK_ID=$(redis-cli -h "$REDIS_HOST" -p "$REDIS_PORT" BLPOP "pod:$POD_NAME:queue" 0 | tail -1)
  export TASK_ID
  echo "[worker] 收到任务: $TASK_ID"

  # 标记 BUSY
  redis-cli -h "$REDIS_HOST" -p "$REDIS_PORT" SET "pod:$POD_NAME:state" "busy"
  redis-cli -h "$REDIS_HOST" -p "$REDIS_PORT" SET "status:$TASK_ID" "running"

  # Fetch spec
  dev-flow-spec fetch "$TASK_ID" > /tmp/input.json
  python3 -c "
import json
d=json.load(open('/tmp/input.json'))
print(f'[worker] goal: {d[\"goal\"][:80]}...')
"

  # 心跳（修复缺陷 2：检查 status 决定是否继续）
  (
    while true; do
      S=$(redis-cli -h "$REDIS_HOST" -p "$REDIS_PORT" GET "status:$TASK_ID")
      [ "$S" != "running" ] && exit 0
      dev-flow-spec heartbeat "$TASK_ID"
      sleep 30
    done
  ) &
  HB_PID=$!

  # Git prepare（reset 契约）
  echo "[worker] git prepare..."
  git fetch origin
  git checkout -B "dev-flow/$TASK_ID" origin/main
  git clean -fdx

  # Build prompt + Run Claude Code
  echo "[worker] starting claude code..."
  export PATH="/usr/local/bin:$PATH"

  GOAL=$(python3 -c "import json; print(json.load(open('/tmp/input.json'))['goal'])")
  ACCEPTANCE=$(python3 -c "
import json
d=json.load(open('/tmp/input.json'))
print(chr(10).join('- '+a for a in d.get('acceptance',[])))
")
  FORBIDDEN=$(python3 -c "
import json
d=json.load(open('/tmp/input.json'))
print(chr(10).join('- '+f for f in d.get('constraints',{}).get('forbidden',[])))
")

  claude --bare -p "你是 dev-flow worker agent。

## 任务目标
$GOAL

## 验收标准
$ACCEPTANCE

## 约束（必须遵守）
$FORBIDDEN

## 完成后
1. git diff origin/main --stat
2. git add + git commit
3. 输出 JSON: {\"status\":\"done\",\"commits\":[\"<sha>\"],\"files_changed\":[\"...\"]}" \
    --output-format json \
    --max-turns 30 \
    --max-budget-usd 1.50 \
    --dangerously-skip-permissions 2>&1 | tee /tmp/claude-raw.json || true

  # Parse output（修复缺陷 1：用 os.environ 不用 heredoc 变量）
  python3 << 'PARSEEOF'
import json, subprocess, os

task_id = os.environ["TASK_ID"]
with open("/tmp/claude-raw.json") as f:
    raw = json.load(f)

diff = subprocess.run(["git", "-C", "/workspace/repo", "diff", "origin/main", "--stat"],
                      capture_output=True, text=True).stdout.strip()
commit = subprocess.run(["git", "-C", "/workspace/repo", "log", "--oneline", "-1"],
                        capture_output=True, text=True).stdout.strip()

output = {
    "task_id": task_id,
    "status": "done" if diff else "blocked",
    "commits": [commit.split()[0]] if commit else [],
    "evidence": {"diff_stat": diff, "claude_cost": raw.get("total_cost_usd", 0)},
    "session_id": raw.get("session_id", ""),
}
with open("/tmp/output.json", "w") as f:
    json.dump(output, f, ensure_ascii=False)
PARSEEOF

  # Submit output
  dev-flow-spec submit "$TASK_ID" /tmp/output.json

  # Push branch
  git push origin "dev-flow/$TASK_ID" || true

  # 停心跳
  kill $HB_PID 2>/dev/null || true

  # Reset（复用纪律 — 设计文档 §5）
  echo "[worker] reset..."
  redis-cli -h "$REDIS_HOST" -p "$REDIS_PORT" SET "pod:$POD_NAME:state" "resetting"
  bash /usr/local/bin/reset.sh
  redis-cli -h "$REDIS_HOST" -p "$REDIS_PORT" SET "pod:$POD_NAME:state" "idle"
  echo "[worker] reset 完成，等待下一个任务"
done
```

---
apiVersion: v1
kind: Namespace
metadata:
  name: dev-flow

apiVersion: v1
kind: Secret
metadata:
  name: dev-flow-secrets
  namespace: dev-flow
type: Opaque
stringData:
  ANTHROPIC_API_KEY: "<智谱 API key>"
  GITEA_SSH_KEY: |
    <Gitea SSH 私钥内容>

apiVersion: apps/v1
kind: Deployment
metadata:
  name: dev-flow-worker
  namespace: dev-flow
spec:
  replicas: 1  # 初始 1 个 pod，按需扩
  selector:
    matchLabels:
      app: dev-flow-worker
  template:
    metadata:
      labels:
        app: dev-flow-worker
    spec:
      containers:
      - name: worker
        image: 192.168.31.200:8080/dev-flow/worker:latest
        imagePullPolicy: Always
        env:
        - name: REDIS_HOST
          value: "redis.infra.svc.cluster.local"
        - name: REDIS_PORT
          value: "6379"
        - name: REPO_URL
          value: "ssh://git@gitea.gitea.svc.cluster.local:22/datavdl/deer-flow.git"
        - name: POD_NAME
          valueFrom:
            fieldRef:
              fieldPath: metadata.name
        - name: ANTHROPIC_API_KEY
          valueFrom:
            secretKeyRef:
              name: dev-flow-secrets
              key: ANTHROPIC_API_KEY
        envFrom:
        - secretRef:
            name: dev-flow-secrets
        volumeMounts:
        - name: ssh-key
          mountPath: /root/.ssh
      volumes:
      - name: ssh-key
        secret:
          secretName: dev-flow-secrets
          items:
          - key: GITEA_SSH_KEY
            path: id_rsa
          defaultMode: 0600

## 5. L0 → L1 改造对照

| # | 组件 | L0 | L1 |
|---|------|----|----|
| 1 | spec 存储 | input.json 本地文件 | Redis `spec:<id>` |
| 2 | output 存储 | output.json 本地文件 | Redis `output:<id>` |
| 3 | worker 执行 | 本地 `claude -p` | Pod 热池接任务 |
| 4 | 状态追踪 | state.json | state.json + Redis 双写 |
| 5 | 心跳 | 无 | Redis TTL 60s |
| 6 | Pod 生命周期 | 无 | 常驻热池 + reset 契约 |
| 7 | L0 本地模式 | 唯一模式 | 保留（mode: local） |
| 8 | intake | 不变 | 不变 |
| 9 | gate | 读本地 git | 读 Redis + 可选 kubectl exec |
| 10 | integrate | 不变 | 不变 |
