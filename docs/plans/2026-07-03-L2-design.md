## 1. 镜像开源 — GitHub Container Registry

```
当前: 192.168.31.200:8080/dev-flow/worker:latest (Harbor 私库，1.08GB)
目标: ghcr.io/tianyue/hermes-dev-flow/worker:latest (公开拉取)

用户安装流程:
  npx hermes-dev-flow setup   → 提示选择镜像源
  → ghcr.io (公开) 或 自建 Harbor
  → docker pull ghcr.io/.../worker:latest
  → kubectl apply -f k8s/
```

**做法**：
- GitHub Actions 自动构建 + push 到 ghcr.io
- `Dockerfile.worker` 已在仓库中，CI 触发器：push tag `v*`
- README 中提供 `docker pull ghcr.io/...` 命令

## 3. 通知 — Hermes 消息 + 邮件

| 事件 | Hermes 消息 | 邮件 | 触发方式 |
