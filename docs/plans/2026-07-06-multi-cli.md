# 多 CLI 择优设计 · 2026-07-06

## 目标

同一任务同时派给 Claude Code 和 Codex，对比产出后选优。

## 架构

```
intake → worker
           ├── Claude Code (子任务A)  → output-A.json
           └── Codex       (子任务B)  → output-B.json
                  ↓
            compare（对比）
           ├── 都有 commit → 对比 diff 质量
           ├── 只有一个有 → 选有的
           └── 都没有 → escalation
                  ↓
              gate（人工确认选哪个）
                  ↓
             integrate
```

## 实现策略

**L0 本地并行**：Hermes 同时起两个 `claude -p` 和 `codex exec`，各自在独立 worktree 分支上执行，然后对比。

**对比维度**（按优先级）：
1. 是否有 commit（有 > 无）
2. diff 行数（越多越完整，但不能差异过大超过 100 行说明偏离需求）
3. 是否有测试文件
4. self_check 是否全部 met

**L1 Pod 模式**：需要两个 Pod 或同一个 Pod 串行两次（Codex 容器限制暂不可用，先做 L0）。
